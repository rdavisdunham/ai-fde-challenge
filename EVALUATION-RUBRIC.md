# Evaluation rubric

Both tracks use the same themes:

- Problem framing: clear user, scope, and success condition
- Working vertical slice: core path runs from input to useful output
- Technical judgement: sensible architecture and tradeoffs
- Observability: operator can understand latency, cost, tool calls, errors, and outcome
- Reliability and safety: uncertainty, failures, retries, unsupported requests, and risky actions handled explicitly
- Evaluation discipline: success is defined and tested, not only demonstrated
- FDE communication: decisions, limitations, and next steps are clear
- Use of AI tools: productive use while retaining ownership of design and tradeoffs
