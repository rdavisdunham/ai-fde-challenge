# AI FDE Challenge

Build a small AI system that can be used by a real operator, not just a chat demo.

Choose one work track:

1. Build a voice agent that can answer queries about the live Brainforge website at https://brainforge.ai.
2. Build an evaluation framework for a software engineering agent that learns from its own logs and gives operators visibility into usage and behaviour.

You have up to three hours. A narrow, complete vertical slice is better than a broad, unfinished platform.

## Start here

- Read [CHALLENGE.md](CHALLENGE.md) for the shared expectations.
- Choose either [Track 1](TRACK-1-VOICE-AGENT.md) or [Track 2](TRACK-2-AGENT-EVALUATION.md).
- Use [SUBMISSION.md](SUBMISSION.md) to prepare your handoff.
- Review [EVALUATION-RUBRIC.md](EVALUATION-RUBRIC.md) before you begin.

## Candidate constraints

- Do not use Brainforge production credentials or private systems.
- Keep secrets out of the repository and logs.
- Do not make real outbound calls or send real messages.
- Use only public information and the supplied repository materials.
- Be explicit about what is real, mocked, or incomplete.

## How to submit

Push your work to a private repository and share access with your Brainforge contact, or send a zip archive by email. Include everything on the [submission checklist](SUBMISSION.md). Confirm your deadline with your Brainforge contact.

## Ownership

The code and materials you produce for this challenge are yours. Brainforge will not reuse your submission outside of evaluating your candidacy.
